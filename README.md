# Test 1 — Basit Statik Sayfa

Tek sayfalık statik HTML teslimi. İçerik `index.html` dosyasının tamamıdır.

## Nasıl açılır

1. `index.html` dosyasını indirin ya da depoyu klonlayın.
2. Dosyayı bir tarayıcıda açın (dosyaya çift tıklamak yeterlidir) veya terminalden `open index.html` (macOS) / `xdg-open index.html` (Linux) komutunu çalıştırın.

## Notlar

- Derleme, paket kurulumu veya sunucu gerekmez; sayfa tek bir HTML dosyasıdır.
- Harici kaynak (font, görsel, script) kullanılmaz, bu yüzden çevrimdışı da açılır.
- Sayfa masaüstü ve mobil genişliklerde taşmadan görüntülenir.
