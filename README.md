# VelaNorth Logistics

VelaNorth Logistics is a fictional, offline-only marketing website built with plain HTML, CSS, JavaScript, procedural Three.js, and GSAP.

## Open locally

Open `index.html` directly in a modern browser. No installation, package manager, build step, backend, or network connection is required.

For an optional local server:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080/`.

## Interaction notes

- Scroll through one connected road, sea, and air route.
- Use the navigation links to move directly to services, the shipment journey, or the quote form.
- The quote form validates entirely in the browser and displays a local confirmation. It never sends or stores data.
- Reduced-motion preferences disable the scroll-driven camera journey while preserving all content and controls.
- If WebGL is unavailable, a designed static route fallback replaces the canvas.

All copy, services, and brand details are fictional. No real company, customer, person, office, certification, performance claim, tracking record, or contact detail is represented.
